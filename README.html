二、chat_server.c — 嵌入式 WebSocket & HTTP 实时聊天服务器

1. 程序概述

chat_server.c 是一个单文件构成的轻量级 Win32 网络服务端程序。它同时兼有 HTTP 静态 Web 服务器、REST API 历史记录接口 以及 WebSocket 全双工实时广播服务器 三大功能。前端界面已完全内置于源码的 HTML_PAGE 字符串中，无需部署外部静态资源。

2. 编译指南

该程序依赖 Windows 网络库 ws2_32、加密库 crypt32 以及 Win32 用户库。支持使用 Zig cc 或 TCC 直接编译成 GUI 无控制台窗口程序：

# 使用 Zig cc 编译 (推荐 -Oz 极小体积优化) zig cc chat_server.c -o chat_server.exe -lws2_32 -lcrypt32 -luser32 -ladvapi32 "-Wl,--subsystem,windows" -Oz -s # 使用 TCC 编译 tcc chat_server.c -o chat_server.exe -lws2_32 -lcrypt32 -luser32 -ladvapi32 -mwindows

3. 关键技术实现与设计亮点

  • 零 MSVCRT 基础函数库替代： 为避免不同 C 运行库的兼容性问题，源码内实现了纯 Win32 替代函数，如 my_alloc/my_free (基于 HeapAlloc), win_strlen, win_memcpy, win_strcmp, win_strstr 等。
  • 原生 CryptoAPI 计算 WebSocket 握手： 补全了 TCC 缺失的 wincrypt.h 函数声明，利用 CryptCreateHash 计算 SHA-1 并用 CryptBinaryToStringA 完成 Base64 编码，安全计算 Sec-WebSocket-Accept 响应。
  • 双重临界区 (Critical Section) 线程同步： 使用 file_lock 保护对磁盘日志文件 messages.txt 的并发追加，使用 clients_lock 保护 WebSocket 客户端链表（ClientNode）的动态添加、删除与广播。
  • WebSocket 完整帧解析： 完全支持基础掩码解码 (Masking)、标准长度、16-bit 扩展长度（Payload == 126）及 64-bit 大包扩展长度（Payload == 127）。

4. 接口与通信协议规范

三、DDCBrightness.c — 显示器 DDC/CI 硬件亮度调节托盘工具

1. 程序概述

DDCBrightness.c 是一款运行在 Windows 系统托盘区（System Tray）的现代硬件亮度控制工具。它不需要依赖显卡驱动软件，而是直接通过系统 dxva2.dll 提供的 DDC/CI (Display Data Channel Command Interface) 协议与外接显示器的固件通信，调节显示器背光亮度。

2. 编译指南

# 使用 TCC 编译 (需要链接 dxva2, gdi32, comctl32 等) tcc .\DDCBrightness.c -o .\DDCBrightness.exe -luser32 -lshell32 -lgdi32 -lcomctl32 -ldxva2 -ladvapi32

3. 核心功能与技术特色

1. DDC/CI Capabilities 硬件型号深度识别

超越 Windows 系统默认给出的泛用“通用 PnP 显示器”命名。本工具通过向显示器发送发送低阶 DDC/CI 指令（CapabilitiesRequestAndCapabilitiesReply），解析响应字符串中的 model(...) 标签，直接获取显示器的真实厂商型号名（例如 Dell U2720Q、LG 27GP850 等）。

2. Windows 10/11 现代化暗色风格 Flyout 悬浮窗

采用精美暗色调设计（背景 #1F1F1F），支持 Segoe MDL2 Assets 矢量图标（亮度图标 \uE706、关屏图标 \uE7E8）。动态加载 dwmapi.dll (启用 DWMWA_USE_IMMERSIVE_DARK_MODE) 与 uxtheme.dll (DarkMode_Explorer) 实现完美暗色主题沉浸。

3. 多显示器独立控制与一键关屏

自动枚举多达 8 台物理显示器（EnumDisplayMonitors），为每台显示器渲染独立的 Trackbar 滑块与实时数值。窗口右上角提供专属硬件熄屏按钮，利用 VCP Code 0xD6 发送节电指令并触发系统休眠。

4. 操作指南

  • 单击托盘图标： 在鼠标指针位置弹出一个类似 Win10 系统原生的 Flyout 亮度调节框，滑动滑块实时改变硬件背光。失焦自动隐藏。
  • 右键托盘图标： 弹出右键菜单，可勾选/取消“开机自启动”（自动写入 HKCU\Software\Microsoft\Windows\CurrentVersion\Run）或完全退出程序。

四、ping_gateway.c — 静默后台网关连通性监控服务

1. 程序概述

ping_gateway.c 是一个轻量级网络连通性诊断工具。程序启动后会立即自动剥离控制台，完全无感地在后台以固定间隔（默认 60 秒）向局域网网关发送 ICMP Echo 探测包，并把网络延迟（RTT）与断网事件写入日志，非常适合用于网络稳定性排查或长期断连统计。

2. 编译指南

# 使用 Zig cc 编译 zig cc -Oz -s ping_gateway.c -o ping_gateway.exe -liphlpapi -lws2_32 -luser32 '-Wl,--subsystem,windows' # 使用 TCC 编译 tcc ping_gateway.c -o ping_gateway.exe -liphlpapi -lws2_32 -luser32 -mwindows

3. 工作原理与设计

  • 隐形后台运行： 源码入口为 WinMain 并首句执行 FreeConsole()，确保即使在 CMD 中调用启动也不会阻塞或留下终端窗口。
  • 智能网关自动感知： 调用 IP Helper API (GetAdaptersInfo) 轮询本机适配器列表，自动检索非 0.0.0.0 的有效默认网关 IP。无需手动配置网关地址。
  • 命令行目标覆盖： 支持命令行参数传入指定 IP（例如：ping_gateway.exe 1.1.1.1），传入参数时将优先监控指定 IP。
  • 原生 ICMP API 免管理员权限： 使用 Win32 系统的 IcmpCreateFile 与 IcmpSendEcho 发送探测包，无需 Raw Socket 权限（普通用户权限即可运行）。

4. 日志格式说明

日志文件存放在当前工作目录下的 log\ping.log 中：

[*] 静默 Ping 监控启动，目标网关: 192.168.1.1 [2026-09-08 10:15:00] Ping 192.168.1.1 - 成功 | 延迟: 1 ms [2026-09-08 10:16:00] Ping 192.168.1.1 - 成功 | 延迟: 2 ms [2026-09-08 10:17:00] Ping 192.168.1.1 - 超时或失败

五、power_monitor.c — 进程感知的电源计划动态切换器

1. 程序概述

power_monitor.c 是一个自动化电源管理后台服务。它可以根据配置的目标进程名单（如游戏 Cyberpunk2077.exe、渲染器 blender.exe 或编译工具 zig.exe）动态调整 Windows 系统电源计划：当发现名单中的进程正在运行时，自动将系统提升至“平衡模式”以释放完整性能；当所有目标进程退出后，自动将系统降低至“节能模式”以降低功耗并减少发热。

2. 编译指南

# 使用 TCC 编译 (可加入 -mwindows 选项隐藏控制台窗口) tcc power_monitor.c -o power_monitor.exe -mwindows

3. 核心机制与架构设计

  • 零静态依赖与 API 动态加载： 程序内包含对 Toolhelp32 进程快照 API 和 powrprof.dll 中 PowerSetActiveScheme 函数的动态解析加载，无需在编译阶段链接额外的扩展库。
  • 低资源消耗轮询： 默认每 60 秒（CHECK_INTERVAL_MS = 60000）检查一次进程快照，CPU 与内存开销几乎为 0。
  • 状态机防抖动： 内部维护 current_mode 状态，只有当“运行状态”发生切换（节能 ↔ 平衡）时，才会真正触发电源 API 调用并记录日志，避免重复调用 API。

4. 配置文件与日志路径

配置文件 D:\zig\config\power_monitor.txt
配置格式 纯文本文件，每行写一个目标可执行文件名称（不区分大小写），例如：
chrome.exe
game.exe
ffmpeg.exe
日志路径 D:\zig\log\power_monitor.log (带时间戳输出模式切换轨迹)

六、start.c — 开机自启动注册表项可视化管理工具

1. 程序概述

start.c 是一款专注于 Windows 开机自自启动项配置的直观 GUI 工具。通过可视化图形界面，帮助用户安全、便捷地为任意程序配置或清除 Windows 注册表自启项（HKCU\Software\Microsoft\Windows\CurrentVersion\Run），并支持自定义附加命令行参数。

2. 编译指南

# 使用 TCC 编译 (链接 comdlg32 文件选择对话框组件) tcc start.c -o start.exe -lkernel32 -luser32 -lgdi32 -ladvapi32 -lcomdlg32

3. 核心特性与实现细节

  • 高分屏 (DPI Awareness) 完美适配： 针对 4K 等高 DPI 缩放屏幕，程序动态优先加载 User32 的 SetProcessDpiAwarenessContext(-4) (Per-Monitor v2)，降级兜底调用 SetProcessDPIAware()，确保高清晰度无模糊界面。
  • 标准 Windows 控件批量构建： 使用自定义的 CTRL_DEF 数组表单配合 Microsoft YaHei UI 字体，批量创建清晰统一的界面元素。
  • 路径与参数智能封装： 自动从选择的文件路径中提取文件名作为注册表键名，若填有启动参数，将自动封装为带转义双引号的标准命令格式："C:\path\app.exe" --arg1。
  • 防重校验机制： 在写入自启项前，会先读取注册表，若该项已存在则弹窗提示，防止重复添加或误覆盖。

4. 使用步骤

  1. 点击 “浏览...” 按钮，通过文件对话框选择需要设为自启动的 .exe 应用程序。
  2. （可选）在 “启动参数:” 输入框中输入程序启动时需要的参数（如 --minimized、-server 等）。
  3. 点击 “添加开机自启”：程序将向注册表写入键值并弹出结果反馈。
  4. 需要取消自启时，只需选择对应程序并点击 “删除开机自启” 即可安全清理。
